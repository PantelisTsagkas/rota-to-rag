Απόρρητο

Η ερώτησή σας στέλνεται κρυπτογραφημένη στην εφαρμογή, που λειτουργεί στο AWS. Την επεξεργάζονται τρία μοντέλα τεχνητής νοημοσύνης (Cohere, Claude Haiku και Claude Sonnet) μέσω του Amazon Bedrock, μόνο σε κέντρα δεδομένων του AWS στην Ευρωπαϊκή Ένωση.

Δεν αποθηκεύουμε την ερώτησή σας πουθενά. Το AWS δεν την κρατά, δεν τη χρησιμοποιεί για την εκπαίδευση μοντέλων και δεν τη μοιράζεται με τις εταιρείες που φτιάχνουν τα μοντέλα, οπότε η Anthropic και η Cohere δεν τη βλέπουν ποτέ.

Η διεύθυνση IP σας κρατιέται μόνο σε μη αναγνώσιμη μορφή (hash) για λίγα λεπτά, για να ισχύει το όριο ερωτήσεων, και μετά διαγράφεται αυτόματα. Αν αξιολογήσετε μια απάντηση, κρατάμε μόνο το «Ναι» ή «Όχι» και τον λόγο που επιλέξατε, χωρίς την ερώτηση, για 90 ημέρες.
